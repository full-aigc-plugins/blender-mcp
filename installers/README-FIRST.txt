PartMe Blender MCP 0.5.0

最简单的安装方式 / Simplest installation:

macOS:
  双击 install_partme_blender_mcp.command
  或运行: ./install_partme_blender_mcp.command

Windows:
  双击 install_partme_blender_mcp.bat

如果你有 Python 3.11-3.13，也可以直接安装当前平台包:
  python -m pip install <this-platform-archive>

然后在 Blender:
  Edit > Preferences > Add-ons > Install from Disk
  选择同目录的 partme-blender-mcp-addon-0.5.0.zip
  启用 PartMe Blender MCP
  按 N > PartMe MCP > Start MCP Server

不要把终端中的 Processing... 或 Successfully installed... 文本再次当作命令执行。
Do not paste pip output such as Processing... back into the shell.
