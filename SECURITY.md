# Security Policy

Report suspected vulnerabilities privately through GitHub Security Advisories for
[full-aigc-plugins/blender-mcp](https://github.com/full-aigc-plugins/blender-mcp/security/advisories/new).

Do not include active credentials, private Blender projects, personal data, or proprietary assets in
a public issue. Version 0.1.x is a pre-release line and does not yet carry a production support SLA.
